# 按题材选择排版

## 情感故事与小说

- 换说话人通常另起一段；同一人物紧密关联的动作、说话人提示和台词可留在一起。分段后应仍清楚谁在说、谁在动。
- 场景、时间或视角切换可以分节；分隔符只标真正的叙事间隔，不按字数周期插入。
- 情绪转折可用短段，场景铺陈与心理叙述可稍长。不要求一句一段，也不将动作和心理一律拆开。
- 默认不用观点加粗、要点清单和“核心结论”标签。信件、聊天、诗歌等保留本身结构；它们不是普通段落长度审查对象。
- 不把缺失的引号直接自动补齐；先判断是否为跨段台词、嵌套引用或真实缺漏。

## 热点评论与民生观察

- 开头交代理解论点所需的背景，按事件与争议的关系组织；不强制固定前言。
- 分清事实、来源说法、解释和判断。一段可以包含紧密关联的证据与解释，不为“一段一意”拆断因果。
- 小标题表达本节的问题或判断。短文通常不需要多层标题，也允许完全不用标题。
- 关键转折可独立成短段，之后用正常段落支撑；避免连续口号式短句。
- 只有需要显式区分证据状态时才少量使用【已确认】等标签，不能靠标签代替核实。

## 科技解释与产品分析

- 按概念、机制、变化、证据、影响组织，但不要求每篇依次套用这五节。
- 每段保持明确主题，开头帮助读者理解本段目的。专业名词解释与必要限定不因拆段分离。
- 同维度的参数、选项可用列表或窄表；比较项多时拆为同维度短列表，不制造横向滚动。
- 代码、版本、路径与数字保持精确，不能执行全局标点替换。没有真实测试材料不得改成第一人称测评。

## 教程与操作指南

- 有先后关系的操作用编号，独立选项用无序列表；一个步骤包含动作与必要结果，不把依赖步骤打散。
- 前提、易错点、代码和示例应可区分；提示贴近对应步骤，不集中堆到结尾。
- 编号是操作关系，不是给所有小标题加“01/02”。代码与引用不套普通正文段长目标。

## 随笔与个人表达

- 按思绪、观察对象与语气变化分段，保留有意重复、犹疑和留白。
- 不强加提纲、总分总或“给读者三条建议”。没有作者经历材料不能以第一人称虚构真实经验。

## 跨类型尺度

长度用于发现密集或破碎的区域，不能证明某一段应该拆分。科技/热点短文可暂以40–100个去空白字符为常见段长参考，150/220以上复查；故事、教程、引用和特殊文本不套这个目标。遇到完整论证可保留长段并说明理由。

重点强调保持稀疏，允许零强调；普通短文可先以不超过约3–5处作为编辑参考，不是强制配额。长文按章节控制，避免每段都有强调。不要同时堆加粗、引号、标签和分隔线。
