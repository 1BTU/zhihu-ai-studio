# 设计参考与取舍

2026-10-23 根据已阅读的来源重新整理为本项目规则，未安装或调用外部脚本。

- [小说分段助手](https://github.com/sgwz1001/Skill-NS-Novel_segmenter/blob/main/SKILL.md)：借鉴保留原稿、修改定位和专名纠错边界；不采用一句一段、45字硬上限及自动补引号。其主文与细则对跨段台词的默认处理有差异，不作为本项目规范。
- [WeChat Editorial Layout](https://github.com/niuer/wechat-editorial-layout-skill/blob/main/SKILL.md)：借鉴语义分段、克制强调、保留事实和渲染校验；不采用固定视觉主题、强制章节编号或公众号HTML作为知乎输出。
- [WXLayoutSkill 编排规则](https://github.com/TanShilongMario/WXLayoutSkill/blob/main/skills/wxlayout-wechat-paste/orchestration.md)：借鉴按题材与局部语义选择布局、限制装饰；不采用必用卡片数量、固定开篇收尾或多色模板。
- [Open University 小说排版](https://www.open.edu/openlearn/mod/oucontent/view.php?id=101090&section=_unit6.3.3)：借鉴场景、时间与视角变化的分节意义；其英国投稿字体、行距和缩进要求不套用到知乎手机端。
- [Google 技术写作：段落](https://developers.google.com/tech-writing/one/paragraphs)：借鉴主题聚焦与避免过长/过碎；英文句数建议不是中文硬指标。

这些来源提供可迁移的方法，不能证明某种排版会提高阅读量、点赞或完读率。后续用真实预览和读者反馈继续修正。
