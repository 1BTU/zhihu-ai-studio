# 观察 → 模式 → 洞见

这是 writing-strategy 候选中最适合当前材料的默认选择；备选为“打破预期 → 新视角”“人物驱动故事”。也比较过“案例 → 分析 → 启示”“比较 → 选择”，避免无材料就套问题解决式框架。

从可指认的事实或处境提出问题，让多个细节之间出现关系，再用一个新解释回应。例子是证据，不是开头的装饰。参考：[回复压力](../cards/sspai-62399.md)、[生活取舍](../cards/sspai-82961.md)、[项目复盘](../cards/sspai-64609.md)。

## 写作前的提纲

1. 读者现在怎么理解这件事？
2. 哪个已经核实的细节解释不了？
3. 两个相互独立的材料支持什么更具体的判断？
4. 这个判断在哪些情况下不成立？
5. 结尾如何回到前面的具体问题？

不要预设反转，不必每篇都从场景开始。只有零散新闻、没有共同关系时，这种结构会制造假洞见。人物驱动备选只有在有真实访谈或记录时才使用；不能为增强代入感编造普通人的故事。
